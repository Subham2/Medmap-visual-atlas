Final Deployment Setup - MedMap Visual Atlas

Complete, deployment-ready build and runtime setup for this project, including OpenAI-compatible provider configuration, production run commands, and release checklist.

Build Verified Runtime Verified Publish Gate: npm run check:publish

1) Environment Template

PORT=3000
NODE_ENV=production
APP_URL=https://your-domain.example

TRUST_PROXY=1

GEMINI_API_KEY=
GEMINI_BASE_URL=
GEMINI_MODEL=gemini-2.5-flash
Never commit secrets. Use a secret manager in production.

2) Core Commands

npm ci
npm run verify   # typecheck + build + publish check
npm start
Invoke-RestMethod -Uri "http://localhost:3000/api/status" -Method GET | ConvertTo-Json -Depth 5
Pass if endpoint returns JSON with configured/source fields.

3) Functional API Smoke Test

$body = @{ symptoms = @('chest pain','shortness of breath') } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:3000/api/analyze-symptoms" -Method POST -ContentType "application/json" -Body $body | ConvertTo-Json -Depth 8
  • Expected: HTTP 200
  • Expected: response contains data.differentials
  • Expected: non-empty medical differential output

4) Docker Production

docker build -t medmap:prod .
docker run --name medmap -p 3000:3000 --env-file .env medmap:prod
curl http://localhost:3000/api/status

5) VM/Server Production

npm ci
npm run verify
npm prune --omit=dev
NODE_ENV=production pm2 start dist/server.cjs --name medmap
pm2 save

6) Reverse Proxy (Nginx)

server {
  listen 80;
  server_name your-domain.example;

  client_max_body_size 1m;

  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
